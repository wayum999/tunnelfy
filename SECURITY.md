## Reporting a Vulnerability

To report a security vulnerability, please follow these steps:

1. **DO NOT** disclose the vulnerability publicly
2. Send details of the vulnerability to [info@tunnelfy.com]
3. You should receive a response within 48 hours
4. If the vulnerability is accepted:
   - We will work on a fix
   - A security advisory will be released once the fix is ready
5. If the vulnerability is declined:
   - You are free to disclose it publicly
   - We will provide an explanation for the decision

We take all security vulnerabilities seriously and appreciate your efforts to responsibly disclose your findings.

## Security Update Process

1. The vulnerability will be investigated
2. A fix will be developed and tested
3. A security advisory will be published
4. Updates will be released to all supported versions

Thank you for helping keep our project and its users secure.
